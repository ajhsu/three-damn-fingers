# Three Damn Fingers: public site

The website of Three Damn Fingers and its privacy policy. GitHub Pages publishes it at
https://ajhsu.github.io/three-damn-fingers/.

- `index.html`: the home page.
- `privacy.html`: the privacy policy. The Microsoft Store listing links to it.
- `style.css` and `icon.svg`: the look of both pages.
- `.nojekyll`: GitHub Pages serves the files as they are.

To publish, open **Settings > Pages** in this repository. Under **Build and deployment**, choose
**Deploy from a branch**, then the `main` branch and the `/ (root)` folder.
